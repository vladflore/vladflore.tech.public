About This Portfolio

Creating a portfolio is a great way to showcase your work and interests. It can also be a strong motivator to keep learning and building once you get started. Not only does it help you highlight your skills and experience to potential employers or clients, but it also helps you stand out from the crowd.

That said, building a portfolio can feel daunting — especially when you’re just starting out.

I’ve put this page together to highlight some of my side projects. It’s not necessarily meant to impress anyone, but rather to keep track of my journey and have a place where I can reflect on how far I’ve come. These projects are built outside of my day job, so they’re intentionally small and focused.

Each project started from a need I had. Instead of using an off-the-shelf solution, I decided to build it myself — giving me the chance to learn something new and tailor the solution to fit my exact requirements and creativity.

Projects

These are small, personal projects created to solve real problems I encountered. As a software engineer, I love exploring new tools and ideas — and when that exploration aligns with a personal need, it becomes a fulfilling and practical learning experience.

1. Algorithms Narrated

Algorithms Narrated is a YouTube video series that visually walks through algorithmic problems (in the spirit of LeetCode), explaining not just the solution, but the reasoning behind each step.

  • 🎯 Step-by-step narrated explanations for better understanding and interview prep

  • 🎥 Video generated with Python, Manim, MoviePy, and Pillow

  • 🔊 Voice narration generated using OpenAI TTS

  • 🌐 Watch the playlist on YouTube

2. Code Box

Code Box is a simple web application that allows me to browse, edit, and run Java and Python code stored in a GitHub repository directly from the browser.

  • 🔧 Built using HTML, CSS and JavaScript. The code editor is the Monaco Editor, and the code is run via a third party API, called Piston, self-hosted

  • 🌐 Try it out

3. vladflore[dot]fit

vladflore[dot]fit is a collection of fitness-related tools and resources I’ve built over time.

💪 Flexary

Flexary started as a way to catalog my fitness exercises. I wanted a simple, searchable library of exercises with images and descriptions to help me remember how to perform them correctly. Additionally, I wanted to be able to create custom workouts by selecting exercises from this library, which I could then export to a PDF for easy reference. There are a couple of more features planned, but the core functionality is already in place.

  • 🔧 Built with PyScript and good old HTML, CSS and JavaScript

  • 🌐 Try it out

🎟️ Hyrox Ticket Radar Telegram Bot

Find HYROX races and get alerts when sold-out tickets reopen or run low. Invite-only.

4. Git Animated

Git Animated is a series of posts and videos I created to help visualize what happens under the hood when running Git commands. The fun part was animating how Git behaves in different scenarios using Manim, a Python library for mathematical animations.

  • 📖 Read the series
  • 💻 View the GitHub repo

The series currently has four parts, with more planned as inspiration (or confusion) strikes.

5. Is It Aired Yet?

As a TV series enthusiast (sometimes too much), I wanted a simple way to check when the next episode of a show is airing. Rather than use existing tools, I built my own web-based interface.

  • 🔧 Built with PyScript

  • 📡 Uses the TVDB API

  • 📈 Simple table-based interface

  • 🌐 Try it out

  • 💻 GitHub repo

Note: The API token used expires monthly. As of writing, it’s valid until 31.05.2025 — so if the app doesn’t work when you check it, that might be why.

6. My Workouts Tracker

After getting more consistent with my workouts, I wanted a better way to track my exercises and weights. A spreadsheet would’ve worked… but where’s the fun in that?

I built a simple web app using PyScript that:

  • 🏋️ Tracks exercises and weight progression

  • 📊 Visualizes trends over time

  • 🌐 Try it out

  • 💻 GitHub repo
