Task

The input is a list of integers sorted in ascending order.

  • has_pair(nums, target): True if two different positions add up to target.
  • find_pair(nums, target): that pair of values (smaller first), or None.

Use two pointers, one at each end: move the left one right if the sum is too small, the right one left if it's too big. That's O(n) time and O(1) extra space; the test counts how often you read the list.

Compare

  • Brute force: check every pair, O(n²) time.
  • Hash set (see Two Sum): O(n) time, O(n) space, works on unsorted input.
  • Two pointers: O(n) time, O(1) space, but only on sorted input.
