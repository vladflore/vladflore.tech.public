Task

A binary tree node has at most two children, left and right. Node and build_tree (from a level-order list) are given.

  • preorder(root: Node | None) -> list[int] (root, left, right), inorder(root: Node | None) -> list[int] (left, root, right), postorder(root: Node | None) -> list[int] (left, right, root): lists of values.
  • height(root: Node | None) -> int: edges on the longest path down from the root; a single node has height 0, an empty tree -1.
  • depth(root: Node | None, value: int) -> int: edges from the root to the node holding value (the root's depth is 0), or -1.
  • is_full(root: Node | None) -> bool: every node has 0 or 2 children.
  • is_complete(root: Node | None) -> bool: every level is full except maybe the last, whose nodes are as far left as possible.

Notes

Traversal visits every node exactly once. Recursion fits trees naturally; for completeness, a level-order walk with a queue (collections.deque) is easier.
