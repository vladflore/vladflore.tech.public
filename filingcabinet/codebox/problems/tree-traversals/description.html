Task

A binary tree node has at most two children, left and right. Node and build_tree (from a level-order list) are given.

  • preorder(root) (root, left, right), inorder(root) (left, root, right), postorder(root) (left, right, root): lists of values.
  • height(root): edges on the longest path down from the root; a single node has height 0, an empty tree -1.
  • depth(root, value): edges from the root to the node holding value (the root's depth is 0), or -1.
  • is_full(root): every node has 0 or 2 children.
  • is_complete(root): every level is full except maybe the last, whose nodes are as far left as possible.

Notes

Traversal visits every node exactly once. Recursion fits trees naturally; for completeness, a level-order walk with a queue (collections.deque) is easier.
