Task

  • price_tag(name: str, price: float) -> str: name left-aligned in 10 characters, then price right-aligned in 8 characters with 2 decimals.
  • percent(part: float, whole: float) -> str: part / whole as a percentage with one decimal, e.g. "42.9%".
  • thousands(n: int) -> str: an integer with comma separators, e.g. "1,234,567".
  • padded_id(n: int) -> str: the number padded with zeros to 5 digits.
  • binary(n: int) -> str: the number in binary, padded with zeros to 8 digits.
  • debug_line(name: str, value: object) -> str: name= followed by the repr of the value, so strings keep their quotes.
  • clean_csv_line(line: str) -> str: split on commas, strip each field, drop empty fields, join the rest with ", ". A line with no non-empty fields gives "".

Example

price_tag("Tea", 3.5)        ->  "Tea           3.50"
debug_line("city", "Oslo")   ->  "city='Oslo'"
clean_csv_line(" a, b ,,c ") ->  "a, b, c"

Notes

  • Every number function is a single f-string with a format spec after the colon: f"{value:spec}". Look up alignment (< >), width, precision, ,, %, 0 padding and b.
  • !r inside the braces uses repr() instead of str().
