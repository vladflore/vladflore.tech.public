Task

  • Stack: push(item: Any) -> None, pop() -> Any (raises IndexError when empty), peek() -> Any (top item or None), is_empty() -> bool, size() -> int, items() -> list (a list, bottom first). Back it with a Python list.
  • reverse_string(text: str) -> str: push every character, then pop them all.
  • to_binary(n: int) -> str: the binary digits of a non-negative int as a string: push n % 2 while dividing by 2, then pop. Don't use bin().

Notes

  • A stack is last in, first out. append and pop at the end of a list are O(1).
  • Checking balanced brackets is the classic stack problem: see Valid Parentheses under Algorithms.
