Task

Write each function as a single comprehension (list, dict or set).

  • positive_squares(numbers: list[int]) -> list[int]: the squares of the numbers greater than zero, in order.
  • labels(numbers: list[int]) -> list[str]: "even" or "odd" for each number.
  • word_lengths(words: list[str]) -> dict[str, int]: a dict from each word to its length.
  • invert(mapping: dict) -> dict: a dict with keys and values swapped (values are unique).
  • initials(names: list[str]) -> set[str]: the set of first letters, upper-cased.
  • flatten(rows: list[list]) -> list: one list with the items of every row, in order.
  • transpose(matrix: list[list]) -> list[list]: rows become columns. All rows have the same length; an empty matrix gives [].

Example

transpose([[1, 2, 3], [4, 5, 6]])  ->  [[1, 4], [2, 5], [3, 6]]

Notes

  • A filter goes at the end (... for n in numbers if n > 0); a choice between two values goes at the front (a if cond else b for ...).
  • Nested for clauses read in the same order as nested loops.
