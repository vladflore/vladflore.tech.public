Task

Search a list sorted in ascending order by halving the range each step.

  • binary_search_recursive(data, target, low, high): True if target is in data[low..high] (both inclusive), recursively.
  • binary_search(data, target): the index of target, or -1, with a loop.

Both must look at about log₂(n) items: the tests count reads on a list of a million numbers.

Notes

  • Binary search only works on sorted data.
  • mid = (low + high) // 2; stop when low > high.
  • The standard library has it too: bisect.bisect_left.
